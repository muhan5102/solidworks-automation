# 实践代码与案例

[当前训练进度](训练进度.md)是状态与成果的总入口。

```text
practice/
  shared/                 多案例共用函数与单件收尾
  year08/<case>/          第8届真题；题目脚本、核验及实践记录
  wangjing/<case>/        王静图集；题目脚本、核验及实践记录
  history/                原阶段进度快照
  训练进度.md             仅维护当前状态和成果索引
```

案例目录保持一层，不为每个小零件复制一套框架。脚本保留描述用途的名字，如 `build_bracket.py`、
`verify_bracket.py`；有阶段参数或修复前提时写在案例记录里，不提供“一键跑全部”入口。

多案例使用的函数放入 `shared/`，不从另一个题目的建模脚本借用函数。
[cad.py](shared/cad.py)复用已安装Skill接口并提供项目辅助函数；
[single_part.py](shared/single_part.py)保留单件保存、导出、重开与人工目视后的收尾逻辑。
题目专属几何、尺寸和检查预期仍由案例负责。修改共用逻辑须检查实际调用者与受影响行为。

维护脚本不等于所有版本都已经从空白重放。每个案例的验证状态和人工提示仍以其记录为准。
历史阶段快照保持原文，其中旧产物地址通过本机迁移表定位；不要把它当作当前执行入口。
