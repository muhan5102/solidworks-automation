## 执行入口

在已确认的SolidWorks会话内，每件先用MCP新建空白零件，使用分别新建的本机输出目录。按下列命令用COM构造回转截面、头部过渡和驱动凹槽，脚本在两个阶段保存。已有文件不覆盖。

```powershell
python -X utf8 practice/year08/fasteners/build_fasteners.py m5 "<M5输出目录>" <PID>
python -X utf8 practice/year08/fasteners/build_fasteners.py m4 "<M4输出目录>" <PID>
```

脚本各自输出SLDPRT、STEP和重开核验资料，实际通过与发生的修正以本轮证据为准。核对对应`review.png`中头形、驱动槽和杆端后，使用同样的命令追加`--visual-notes "<实际目视结论>"`保存关闭，再进入下一件。STEP未重导入SolidWorks、螺纹和真实装配需另验证。

如果失效发生在主体保存后、凹槽保存前，可保全失败态，再重开对应的已保存主体，追加`--resume-body`只续建凹槽。该入口要求同一完整路径、干净文档和只有一条主体阶段记录，且从未生成STEP或终检。M5原六边形坐标补尺寸一次欠定义，改为同一构造圆、六等边及顶点归轴，驱动对边4.1对应的外接圆直径。
