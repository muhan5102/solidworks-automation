# 常用件参数化模板

入口：SolidWorks“新建 → 常用件”；模板位置已由用户在软件中配置。
实际本机路径与原始检查结果保留在未纳管的 `outputs/template-spring-probe-20261114-r01/`，不复制源模板进仓库。

- 已发现：衬套/垫圈，直/斜/锥齿轮，直/斜齿条，内齿圈，左右旋蜗轮、蜗杆，压缩/拉伸/截锥/扭转弹簧，以及装配体与A3图纸模板。
- 常用件先匹配已有模板；确认题目结构、驱动参数和适用范围后，通过模板新建派生文档、修改参数、重建并保存独立原生文件，不覆盖模板。
- 本轮验证对象：压缩弹簧V1.4。`d`为线径，`D1`为外径，`n1`为总圈数，`n`为有效圈数，`H`为高度；内置螺旋线、扫描及两端磨平特征。
- 调用方法：`new_document(sw, "part", template_path)`，读取`GetEquationMgr`，按变量名定位方程索引；通过Equation属性写入带明确单位的值，再EvaluateAll、重建、保存重开、回读驱动尺寸。不要硬编码所有模板共有的方程索引。
- 实测将默认`d=5、D1=50、H=100`改为`2mm、20mm、40mm`；总圈数8、有效圈数6保持默认。重开后`D3@扫描1=0.002m`、`D2@草图94=0.020m`、`D1@草图94=0.040m`，单实体，模板哈希未变，预览已检查。
- 4.573秒仅为派生模型的改参、重建、保存重开与预览调用时间，不含寻找模板、理解参数及首次新建。
- 这是模板调用验证样件，不是第8届真题弹簧。其它模板尚未逐一验证；压缩弹簧的端圈、节距、旋向、磨平及高度定义须与题目核对后才用于交付。

## 直齿轮模板验证

- 直齿轮V1.2模板可直接通过API新建并改方程，无需插件表单。驱动变量包括`m`模数、`z`齿数、`a`压力角、`B`齿宽、`C1`轮齿倒角、`x`变位系数、`ha`齿顶高系数、`c`顶隙系数和`R`齿根圆角。
- 实测保留`m=2、a=20、x=0`，将`z=40`改为24、`B=15`改为10mm；保存重开后单实体、两个模板分支的圆周阵列驱动齿数24，分度圆48mm、齿顶圆52mm、齿根圆43mm、齿宽10mm驱动尺寸均正确，预览已查看，源模板哈希未变。
- 初次新建调用2.117秒，改参、重建、保存重开与预览调用4.936秒；不含理解参数和工具周转。证据在`outputs/template-spur-gear-20261114-r01/inspection.json`。
- 这是无轴孔验证样件，不是制造级齿形验收或课程成果。实际齿轮按题目继续处理孔、轮毂、键槽与其它要求；已验证上述参数组合，不推断所有变位、倒角或其它模板均可稳定调用。
