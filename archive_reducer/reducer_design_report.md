- 材料：小齿轮 40Cr 调质，大齿轮 45 钢调质（软齿面）
- 按齿面接触强度初算中心距 a ≥ 115.4 mm，圆整取 a = 125 mm
- 模数 m = 2.5（GB/T 1357 第一系列），z₁ = 20，z₂ = 80，u = 4.0
- 分度圆 d₁ = 50.0 mm，d₂ = 200.0 mm；齿宽 b₁ = 55 mm，b₂ = 50 mm
- 圆周速度 v = 3.72 m/s → 选 8 级精度（GB/T 10095.1）
- 接触应力 σH = 343.7 MPa ≤ [σH] = 550.0 MPa ✓
- 弯曲应力 σF1 = 36.4 MPa ≤ [σF1] = 290.0 MPa ✓
- 弯曲应力 σF2 = 32.9 MPa ≤ [σF2] = 240.0 MPa ✓

## 4 平键（GB/T 1095-1096）

- 高速轴齿轮座：键 8×7×40；高速轴联轴器：键 6×6×32
- 低速轴齿轮座：键 14×9×40；低速轴联轴器：键 10×8×50

## 5 箱体（HT200，经验公式）

- 箱座壁厚 δ = 0.025a+1 = 4.1 → 取 8 mm（≥8）
- 箱盖壁厚 δ₁ = 0.02a+3 = 5.5 → 取 8 mm
- 凸缘厚 b = b₁ = 12 mm；底座凸缘 b₂ = 20 mm
- 地脚螺栓 df = 0.036a+12 = 16.5 → M16×4
- 轴承旁螺栓 d₁ = 0.75df → M12；箱盖-箱座螺栓 d₂ = 0.5df → M10
- 端盖螺钉 d₃ → M8；视孔盖螺钉 d₄ → M6；定位销 φ8
- 轴心高度 h = 140 mm（齿根离底面 ≥ 15 mm，油池润滑）
- 润滑与密封：齿轮油池润滑（浸油 1~2 模数），轴承脂润滑；通气器、油标、放油螺塞均按课程设计常规配置
